# Tschaikowsky für Kinder

Lern-App für Grundschulkinder. Alle Texte lassen sich mit dem 🔊-Symbol vorlesen.

## Auf GitHub starten (GitHub Pages)

1. Neues Repository anlegen und `index.html`, `README.md` und den Ordner `audio/` hochladen.
2. Im Repository: **Settings → Pages**.
3. Unter *Branch* `main` und `/ (root)` wählen, dann **Save**.
4. Nach etwa einer Minute ist die App unter `https://DEIN-NAME.github.io/REPO-NAME/` erreichbar.

## Hörproben

Lege die Musikausschnitte als MP3-Dateien in den Ordner `audio/`. Die Namen müssen genau so lauten:

- `schwanensee.mp3`
- `nussknacker.mp3`
- `zuckerfee.mp3`
- `blumenwalzer.mp3`

Tschaikowskys Musik ist gemeinfrei. Aufnahmen können aber urheberrechtlich geschützt sein. Geeignet sind frei lizenzierte Aufnahmen, zum Beispiel von Wikimedia Commons oder Musopen. Bitte die Lizenzbedingungen beachten und die Quelle nennen.

Ohne die Dateien zeigt die App einen freundlichen Hinweis.

## Hinweise

- Das Vorlesen nutzt die Sprachausgabe des Browsers. Die Stimme hängt vom Gerät ab.
- Die Schneeflocken sind aus, wenn im Gerät „Bewegung reduzieren“ eingestellt ist.
